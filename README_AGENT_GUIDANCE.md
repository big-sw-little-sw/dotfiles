# Agent guidance dotfiles notes

This is a human deployment note, not an agent instruction file. Do not symlink this file into any tool guidance path.

## Mental model

Keep these concerns separate:

```text
dotfiles
- Always-on global guidance files.
- Tool home/config directory shape.
- Heavy redirection through ~/.local-heavy.

my-agent-config
- Skill source files.
- Prompt/command/workflow content.
- Generated skill symlinks.
- Install manifests.
```

Within dotfiles:

```text
stow/common/
- Canonical global guidance text.
- Safe to stow everywhere.

stow/agent-guidance-*/
- Normal-mode tool-facing guidance files.
- Use when the tool directory lives directly under $HOME.

stow/heavy-links/
- $HOME redirects into ~/.local-heavy.
- Storage policy only.

stow/heavy-dirs/
- ~/.local-heavy skeleton directories and .gitkeep files only.
- No durable guidance files here.

stow/agent-guidance-heavy/
- Heavy-mode durable guidance files inside ~/.local-heavy targets.
- Use only when agent tool directories are redirected through heavy-links.
```

Do not put all tool-facing guidance under `common`. `common` should stay unconditional. Tool-facing packages are intentionally separate because normal mode and heavy mode need different ownership of the same tool directories.

## The important Stow rule for agent guidance

For normal-mode agent guidance, use `--no-folding`.

Agent tool directories such as `~/.claude`, `~/.codex`, `~/.pi`, `~/.cline`, `~/.agents`, and `~/.config/opencode` are not just config-file locations. Tools may also write runtime data, caches, transcripts, settings, generated skills, or other local state under them.

Without `--no-folding`, GNU Stow may fold a missing directory by making the whole tool directory a symlink into the dotfiles package. Example bad normal-mode result:

```text
~/.claude -> ~/sw/code/dotfiles/stow/agent-guidance-claude/.claude
```

That makes later generated files land inside the dotfiles repo. For example, a global `my-agent-config` install could write:

```text
~/.claude/skills/do-design-review
```

which would actually become:

```text
~/sw/code/dotfiles/stow/agent-guidance-claude/.claude/skills/do-design-review
```

That is not what we want.

Preferred normal-mode result:

```text
~/.claude/                         # real directory owned by the tool/user
~/.claude/CLAUDE.md -> dotfiles/... # Stow-managed guidance file
~/.claude/skills/...               # generated by my-agent-config, not dotfiles
```

Preferred heavy-mode result:

```text
~/.claude -> ~/.local-heavy/agent-tools/claude
~/.claude/CLAUDE.md                # guidance file inside heavy target
~/.claude/skills/...               # generated by my-agent-config inside heavy target
```

So the rule is:

```text
Normal mode: use agent-guidance-* with --no-folding.
Heavy mode: use heavy-dirs + heavy-links + agent-guidance-heavy.
Never use normal and heavy ownership for the same tool path.
```

## Normal mode: macOS or Linux without heavy redirection

Use this when tool directories should live directly under `$HOME`.

Choose only the tools you want:

```bash
cd ~/sw/code/dotfiles/stow

stow -n --no-folding -R --target="$HOME" \
  agent-guidance-claude \
  agent-guidance-codex \
  agent-guidance-opencode \
  agent-guidance-pi \
  agent-guidance-cline

# If the dry-run looks good:
stow --no-folding -R --target="$HOME" \
  agent-guidance-claude \
  agent-guidance-codex \
  agent-guidance-opencode \
  agent-guidance-pi \
  agent-guidance-cline
```

You can include `common` in the same command, but it does not need special folding behavior:

```bash
stow -R --target="$HOME" common macos
stow --no-folding -R --target="$HOME" agent-guidance-claude agent-guidance-codex
```

If you prefer to make the target directories explicit first:

```bash
mkdir -p \
  ~/.claude \
  ~/.codex \
  ~/.config/opencode \
  ~/.pi/agent \
  ~/.cline/rules \
  ~/.agents \
  ~/.clinerules

cd ~/sw/code/dotfiles/stow
stow --no-folding -R --target="$HOME" agent-guidance-claude agent-guidance-codex agent-guidance-opencode agent-guidance-pi agent-guidance-cline
```

## Heavy mode: Linux with ~/.local-heavy

Use this when agent tool directories should live under local heavy storage.

Prerequisite: `~/.local-heavy` exists and points to a machine-local disk.

```bash
cd ~/sw/code/dotfiles/stow

stow -n -R --target="$HOME" common linux heavy-dirs heavy-links agent-guidance-heavy

# If the dry-run looks good:
stow -R --target="$HOME" common linux heavy-dirs heavy-links agent-guidance-heavy
```

Do not also stow normal packages for the same redirected tool path.

For example, choose one:

```text
Claude normal:
- agent-guidance-claude with --no-folding

Claude heavy:
- heavy-dirs + heavy-links + agent-guidance-heavy
```

Do not use both for `~/.claude`.

## Check for accidental Stow folding

Run this after stowing agent guidance:

```bash
for p in \
  ~/.claude \
  ~/.codex \
  ~/.pi \
  ~/.cline \
  ~/.agents \
  ~/.clinerules \
  ~/.config/opencode
 do
  echo "== $p"
  if [ -e "$p" ] || [ -L "$p" ]; then
    ls -ld "$p"
    if [ -L "$p" ]; then
      printf 'points to: '
      readlink "$p"
    fi
  else
    echo "missing"
  fi
 done
```

Bad normal-mode result:

```text
~/.claude -> .../dotfiles/stow/agent-guidance-claude/.claude
```

Good normal-mode result:

```text
~/.claude is a real directory
~/.claude/CLAUDE.md is a symlink or stowed file from dotfiles
```

Good heavy-mode result:

```text
~/.claude -> ~/.local-heavy/agent-tools/claude
```

## Recovery: undo an accidental folded normal-mode install

Use this if you already see something like:

```text
~/.claude -> ~/sw/code/dotfiles/stow/agent-guidance-claude/.claude
```

### Step 1: inspect what was folded

```bash
for p in ~/.claude ~/.codex ~/.pi ~/.cline ~/.agents ~/.clinerules ~/.config/opencode; do
  echo "== $p"
  ls -ld "$p" 2>/dev/null || true
  [ -L "$p" ] && readlink "$p"
done
```

If a symlink points into `~/sw/code/dotfiles/stow/agent-guidance-*`, it is a folded normal-mode directory.

### Step 2: unstow the affected normal package

Example for Claude:

```bash
cd ~/sw/code/dotfiles/stow
stow -D --target="$HOME" agent-guidance-claude
```

For multiple normal packages:

```bash
cd ~/sw/code/dotfiles/stow
stow -D --target="$HOME" \
  agent-guidance-claude \
  agent-guidance-codex \
  agent-guidance-opencode \
  agent-guidance-pi \
  agent-guidance-cline
```

If Stow leaves the folded symlink behind, inspect it before removing it:

```bash
ls -ld ~/.claude
readlink ~/.claude
```

If it points into your dotfiles `agent-guidance-claude` package and you have already unstowed that package, remove the symlink:

```bash
rm ~/.claude
```

Repeat only for affected folded paths.

### Step 3: remove generated files that accidentally landed in the dotfiles package

If you ran global `my-agent-config` while folded, generated skill links may have landed in the Stow package.

Inspect first:

```bash
find ~/sw/code/dotfiles/stow/agent-guidance-claude/.claude -mindepth 1 -maxdepth 3 -print
```

Expected durable file:

```text
CLAUDE.md
```

Suspicious generated directories:

```text
skills/
commands/
prompts/
workflows/
```

Remove only generated outputs you recognize. Example:

```bash
rm -rf ~/sw/code/dotfiles/stow/agent-guidance-claude/.claude/skills
```

Do the same for other affected packages if needed.

### Step 4: create real tool directories

```bash
mkdir -p \
  ~/.claude \
  ~/.codex \
  ~/.config/opencode \
  ~/.pi/agent \
  ~/.cline/rules \
  ~/.agents \
  ~/.clinerules
```

### Step 5: restow with no folding

```bash
cd ~/sw/code/dotfiles/stow

stow --no-folding -R --target="$HOME" \
  agent-guidance-claude \
  agent-guidance-codex \
  agent-guidance-opencode \
  agent-guidance-pi \
  agent-guidance-cline
```

### Step 6: verify

```bash
# Tool dirs should not point into dotfiles/stow/agent-guidance-* in normal mode.
for p in ~/.claude ~/.codex ~/.pi ~/.cline ~/.agents ~/.clinerules ~/.config/opencode; do
  echo "== $p"
  ls -ld "$p" 2>/dev/null || true
  [ -L "$p" ] && readlink "$p"
done

# Guidance files should exist.
ls -la ~/.claude/CLAUDE.md
ls -la ~/.codex/AGENTS.md
ls -la ~/.pi/agent/AGENTS.md
ls -la ~/.config/opencode/AGENTS.md
ls -la ~/.cline/rules/global-agent-defaults.md
```

## my-agent-config global installs and dotfiles

Global `my-agent-config` installs should not write into the dotfiles repo.

Before running global install, verify normal-mode directories are real directories, not folded Stow links into dotfiles:

```bash
for p in ~/.claude ~/.codex ~/.pi ~/.cline ~/.agents ~/.clinerules ~/.config/opencode; do
  if [ -L "$p" ]; then
    target=$(readlink "$p")
    case "$target" in
      *dotfiles/stow/agent-guidance-*)
        echo "BAD: $p is folded into dotfiles: $target"
        ;;
      *)
        echo "OK symlink: $p -> $target"
        ;;
    esac
  else
    echo "OK directory or missing: $p"
  fi
done
```

Then global skills can be installed from `my-agent-config`:

```bash
cd ~/sw/code/my-agent-config
python setup.py status --scope global --tool all
python setup.py install --scope global --tool all
python setup.py status --scope global --tool all
```

Generated skill links should live in tool directories or heavy targets, not inside dotfiles.

Version-control these in `dotfiles`:

```text
stow/common/.config/agent-guidance/global-agent-defaults.md
stow/agent-guidance-*/...
stow/heavy-links/...
stow/heavy-dirs/...
stow/agent-guidance-heavy/...
```

Version-control these in `my-agent-config`:

```text
design/*.md
skills/*/SKILL.md
setup.py
```

Do not version-control generated install outputs in dotfiles:

```text
~/.claude/skills/*
~/.agents/skills/*
~/.pi/agent/skills/*
~/.config/opencode/skills/*
~/.config/opencode/commands/*
~/.cline/skills/*
~/.config/my-agent-config/install-manifest.json
```

## Git ignore trap for Claude

If `stow/agent-guidance-claude/.claude/CLAUDE.md` is not showing up in `git status`, check `.gitignore`:

```bash
cd ~/sw/code/dotfiles
git check-ignore -v stow/agent-guidance-claude/.claude/CLAUDE.md
```

A rule like this ignores any `.claude` directory anywhere in the repo:

```gitignore
.claude/
```

Prefer anchoring it to the repo root if you only want to ignore a root-level local Claude workspace:

```gitignore
/.claude/
```

Then verify:

```bash
git check-ignore -v stow/agent-guidance-claude/.claude/CLAUDE.md || echo "not ignored"
```

## Updating dotfiles later

After pulling dotfiles updates, re-run Stow with the same package set for that machine.

Normal mode example:

```bash
cd ~/sw/code/dotfiles
git pull
cd stow
stow -n --no-folding -R --target="$HOME" agent-guidance-claude agent-guidance-codex
stow --no-folding -R --target="$HOME" agent-guidance-claude agent-guidance-codex
```

Heavy mode example:

```bash
cd ~/sw/code/dotfiles
git pull
cd stow
stow -n -R --target="$HOME" common linux heavy-dirs heavy-links agent-guidance-heavy
stow -R --target="$HOME" common linux heavy-dirs heavy-links agent-guidance-heavy
```

Your current `scripts/setup.sh` may stow only `common`, the OS package, and heavy packages. If you want agent guidance packages applied automatically, update `setup.sh` to include your selected packages.

For normal mode, add `--no-folding` to the agent guidance stow call:

```bash
stow $STOW_FLAGS --no-folding --target="$HOME" \
  agent-guidance-claude \
  agent-guidance-codex
```

For heavy mode, add `agent-guidance-heavy` to the existing heavy package command:

```bash
stow $STOW_FLAGS --target="$HOME" heavy-dirs heavy-links agent-guidance-heavy
```

Keep normal vs heavy decisions explicit. Do not hide them inside `common`.

## Source of truth for guidance text

The canonical text is:

```text
stow/common/.config/agent-guidance/global-agent-defaults.md
```

Tool-facing files in normal and heavy Stow packages are regular-file copies for copy/Stow robustness. If you change the canonical global defaults, refresh those copies before committing.

Suggested refresh command from the dotfiles repo root:

```bash
src=stow/common/.config/agent-guidance/global-agent-defaults.md
cp "$src" stow/agent-guidance-claude/.claude/CLAUDE.md
cp "$src" stow/agent-guidance-codex/.codex/AGENTS.md
cp "$src" stow/agent-guidance-opencode/.config/opencode/AGENTS.md
cp "$src" stow/agent-guidance-pi/.pi/agent/AGENTS.md
cp "$src" stow/agent-guidance-cline/.cline/rules/global-agent-defaults.md
cp "$src" stow/agent-guidance-heavy/.local-heavy/agent-tools/claude/CLAUDE.md
cp "$src" stow/agent-guidance-heavy/.local-heavy/agent-tools/codex/AGENTS.md
cp "$src" stow/agent-guidance-heavy/.local-heavy/agent-tools/opencode/AGENTS.md
cp "$src" stow/agent-guidance-heavy/.local-heavy/agent-tools/pi/agent/AGENTS.md
cp "$src" stow/agent-guidance-heavy/.local-heavy/agent-tools/cline/rules/global-agent-defaults.md
```
